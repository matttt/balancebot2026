# WheeledBipedSim

Webots simulation of a two-wheeled biped robot with a PD balance controller and feedforward steering.

## Install Webots

Download and install **Webots R2025a** from [cyberbotics.com/doc/guide/installation-procedure](https://cyberbotics.com/doc/guide/installation-procedure).

## Run the Simulation

1. Open Webots
2. **File → Open World** → navigate to `worlds/balance_sim.wbt`
3. Press the **Play** button

The controller starts automatically. Balance telemetry prints to the Webots console.

## Keyboard Controls

| Key | Action       |
|-----|--------------|
| `W` | Lean forward |
| `S` | Lean back    |
| `A` | Turn left    |
| `D` | Turn right   |
